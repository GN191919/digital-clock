# Digital Clock

A customizable digital clock web app built with HTML, CSS, and JavaScript.
<img width="1277" height="970" alt="image" src="https://github.com/user-attachments/assets/a16b4eb9-31c0-481f-9261-128a806adab0" />


## Features

- Real-time digital clock display
- Multiple color themes: red, green, blue, orange
- Customizable appearance: remove/keep reflection, hide seconds, 24 hour vs 12 hour format
- Installable Progressive Web App (PWA)

## Technologies

- HTML5
- CSS3
- JavaScript
- Web App Manifest

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `digital_clock.html` using a local development server, such as the Live Server extension in Visual Studio Code.
